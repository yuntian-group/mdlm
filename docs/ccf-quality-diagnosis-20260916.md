Historical September 16, 2026. A favorable one-sample separate-R8 DD checkpoint
screen was followed by nine new seeds. The historical selected sample is kept
separate; combining it would mix selection, hardware and code versions.

The nine new samples range from PPL 52.595 to 212.228. Generation uses length
1024, batch 1 and 1,000 transitions plus cleanup, with the pinned GPT-2-large
float32/EOS scoring policy. This shows why the selected one-sample result
should not be treated as a stable checkpoint estimate. Cross-hardware seeded
replay discrepancies are not resolved by this aggregate.

The plotting script preserves logged training/validation convergence analysis.
It does not convert training loss into generative PPL. The first/last three
validation-loss means were 5.8651/5.7828, with changing corruption and a domain
change between training and validation; that is not clean evidence of simple
validation overfitting.

## Exact CPU mechanism probes

`python scripts/diagnose_ccf_objective.py` checks both inference backends.
No language-model text is generated by these probes.

| Quantity | Independent toy | Learned toy joint |
|---|---:|---:|
| Joint cross-entropy per pair | 1.386294 | 0.846432 |
| Singleton cross-entropy per token | 0.693147 | 0.747163 |
| Reveal-kernel token cross-entropy at r=0.001 | 0.693147 | 0.746839 |

Joint improvement can coexist with worse singleton predictions. In a separate
explicit/residual probe, multiplying the explicit pair block by four changes
explicit mass from 0.5 to 0.714286. Neutral factors recover backbone probabilities
in dense and low-rank inference; this is distributional equality, not equality
of seeded draws between two different samplers. A gradient probe confirms that
joint NLL trains factors while discrete topology choices use their separate
auxiliary target.

These mechanisms are possibilities, not a measured diagnosis of all trained
checkpoints. The original held-out joint/marginal/backbone comparison remained
proposed, and this curation does not claim it has run. CPU assertions were rerun
successfully; historical GPU measurements were not rerun.

Related methods to cite when developing these ideas further:
[Discrete Copula Diffusion](https://arxiv.org/abs/2410.01949) for separating
marginal quality from dependence, and [DEMASK](https://arxiv.org/abs/2604.02560)
for reveal-influence supervision. Those methods are not claimed to be identical
to this toy construction or the existing gold-reveal topology teacher.
